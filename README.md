Neon Harbor is an original top-down 2D open-world crime game: run with the Harbor Kings crew, steal and drive cars through a neon city, outrun the Harbor PD's three-star wanted system, and finish six linked story missions to take the docks from the rival Dock Rats.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD/arrows to move and drive, E to steal/enter a car, F to punch, mouse to aim and click to shoot, Shift to sprint, P to pause, M to mute. The game is plain static files under `game/` — no build step, no network requests, no external assets. Progress saves to localStorage.
